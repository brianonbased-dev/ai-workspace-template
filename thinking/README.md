# Thinking Modules

This folder stores visible reasoning scaffolds for local and hosted agents.

- `loops/`: repeatable reasoning loops.
- `questions/`: Absorb, Graph RAG, and domain question banks.
- `playbooks/`: workflows agents can execute.
- `retrospectives/`: sanitized decision records and after-action notes.

Do not store hidden chain-of-thought here. Store protocols, decisions, evidence, and lessons.
