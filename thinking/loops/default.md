# Default Agent Loop

1. Read the task and workspace policy.
2. Check `SKILLS.md`.
3. Select the owning skill, tool, playbook, or agent.
4. Query existing knowledge and Absorb before inventing.
5. Act locally or through scoped services.
6. Verify with the smallest meaningful proof.
7. Write receipts and compress reusable learning.

## Failure Branch

If verification fails:

1. Save the failing evidence.
2. Trigger HoloHeal.
3. Trigger HoloClaw if a repair path is clear.
4. Update `knowledge/gotchas/` if the failure can recur.
