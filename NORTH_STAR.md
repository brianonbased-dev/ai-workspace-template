# Workspace North Star

This workspace exists to give each user a sovereign local AI ecosystem: agents that know the user, own their memory with them, use skills before improvising, and build useful things on the user's hardware and connected services.

## Direction

- The user owns the workspace, memory, policies, and audit trail.
- Agents act from this repo first, then call hosted services with scoped authority.
- Hardware is part of the product. Local GPU, browser, filesystem, repos, and IDEs are sources of experimentation and proof.
- Hosted services add reach; they do not replace local sovereignty.
- Every improvement should leave a reusable module, receipt, or knowledge entry behind.

## Decision Order

1. Use `SKILLS.md` to find the right skill or tool.
2. Use `THINKING.md` for the reasoning loop.
3. Use `SECRETS.md` before any credential or account action.
4. Use `CAPABILITIES.md` before claiming a service, API, or tool is missing.
5. Use `knowledge/` and Absorb before starting from scratch.
6. Act, verify, and compress learning into `knowledge/` or `MEMORY.md`.

## Escalation

Escalate only when the action is irreversible, spends money beyond workspace policy, changes custody of secrets or funds, or publishes outside the user's approved boundary.

Everything else should become a documented local decision with evidence.
