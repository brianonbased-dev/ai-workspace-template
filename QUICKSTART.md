# HoloScript Platform Quickstart (5 minutes)

This guide shows how a non-HoloLand product consumes public HoloScript APIs to compile, preview, and deploy spatial content.

**What you need**

- A HoloScript API key (from your Studio account or team admin)
- Any HTTP client (curl, Postman, fetch)
- 5 minutes

Base URL: `https://mcp.holoscript.net`

---

## Run a complete example (copy/paste)

```bash
export HOLOSCRIPT_API_KEY="<your-key>"

# 1) Compile to React Three Fiber
curl -X POST "https://mcp.holoscript.net/api/compile" \
  -H "Authorization: Bearer $HOLOSCRIPT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code":"object Cube { position: [0,1,0] }","target":"r3f"}'

# 2) Render a preview
curl -X POST "https://mcp.holoscript.net/api/render" \
  -H "Authorization: Bearer $HOLOSCRIPT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code":"object Cube { position: [0,1,0] }","format":"preview"}'

# 3) Deploy a permanent scene
curl -X POST "https://mcp.holoscript.net/api/deploy" \
  -H "Authorization: Bearer $HOLOSCRIPT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"projectName":"quickstart-demo","target":"r3f","code":"object Cube { position: [0,1,0] }"}'
```

**Key scope note:** use `HOLOSCRIPT_API_KEY` for HoloScript product endpoints. Do not substitute `HOLOMESH_API_KEY` (team board API) — it has different scopes.

---

## 1) Compile to your target

Send HoloScript code + target to the compile endpoint.

`POST /api/compile`

**Verified targets**

| Target | Output | Verified |
|--------|--------|----------|
| `r3f` | React Three Fiber scene graph (JSON) | Yes |
| `unity` | C# MonoBehaviour script | Yes |
| `godot` | GDScript scene | Yes |
| `urdf` | ROS 2 / Gazebo robot description (XML) | Yes |
| `sdf` | Gazebo simulation description (XML) | Yes |
| `unreal` | JSON scene descriptor | Yes |
| `dtdl` | Azure Digital Twins JSON-LD | Yes |

```bash
curl -X POST "https://mcp.holoscript.net/api/compile" \
  -H "Authorization: Bearer $HOLOSCRIPT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code":"object Cube { position: [0,1,0] }","target":"unity"}'
```

**Expected response shape:**

```json
{
  "success": true,
  "jobId": "compile_...",
  "target": "unity",
  "output": "// Auto-generated by HoloScript UnityCompiler\n...",
  "warnings": [],
  "metadata": {
    "compilationTimeMs": 2,
    "circuitBreakerState": "CLOSED",
    "usedFallback": false,
    "outputSizeBytes": 588
  }
}
```

## 2) Render a preview

Generate a shareable preview from your composition.

`POST /api/render`

```bash
curl -X POST "https://mcp.holoscript.net/api/render" \
  -H "Authorization: Bearer $HOLOSCRIPT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code":"object Cube { position: [0,1,0] }","format":"preview"}'
```

**Expected response:**

```json
{
  "success": true,
  "url": "https://mcp.holoscript.net/api/scene/{id}/thumbnail",
  "previewUrl": "https://mcp.holoscript.net/scene/{id}",
  "embedCode": "<iframe src=...></iframe>"
}
```

---

## 3) Deploy a scene

Create a permanent scene object with `id`, `url`, `embed`, and `api` links.

`POST /api/deploy`

```bash
curl -X POST "https://mcp.holoscript.net/api/deploy" \
  -H "Authorization: Bearer $HOLOSCRIPT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"projectName":"my-platform-scene","target":"r3f","code":"object Cube { position: [0,1,0] }"}'
```

**Expected response (HTTP 201):**

```json
{
  "id": "59ceaef3",
  "url": "https://mcp.holoscript.net/scene/59ceaef3",
  "embed": "https://mcp.holoscript.net/embed/59ceaef3",
  "api": "https://mcp.holoscript.net/api/scene/59ceaef3"
}
```

## Common errors

| Status | Cause | Fix |
|--------|-------|-----|
| 401/403 | API key missing or invalid | Check `Authorization: Bearer $HOLOSCRIPT_API_KEY` |
| 400 | Request body shape mismatch | Verify JSON fields: `code`, `target`, `projectName` |
| 429 | Rate limited | Retry with exponential backoff |
| 5xx | Server-side issue | Retry; include `jobId` in support reports |

## Next steps

- **Multi-target pipeline:** compile the same `.holo` source to `r3f`, `unity`, and `urdf` in one CI step
- **Embed previews:** use the `embedCode` from `/api/render` in your product dashboard
- **Programmatic deploy:** chain `/api/compile` -> `/api/render` -> `/api/deploy` for a one-click publish flow
- **MCP integration:** use the HoloScript MCP server (`https://mcp.holoscript.net`) for agent-driven compilation from natural language
